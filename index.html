  • 경유거실은 직접배출 필수
§2.2.3 통로 제외 조건
  • 주요구조부 내화구조
  • 마감 불연·난연재료
  • 통로 내 가연성 물질 없을 것

① 탭 「① 배출량 계산」 → 공사명 "만민 건축사 신축공사 현장", 설계자 "김만민" 기본 입력
② 출력 계산서 상단에 자동 반영됩니다.
2
💨 배출량 계산
제연구역 유형·제연경계 여부·수직거리·바닥면적 입력 → [배출량 계산] 클릭
NFTC 501 §2.3 기준으로 배출량·유입구 면적이 자동 산출됩니다.
3
🏗️ 각 탭별 검토
② 제연구역 설계 → ③ 풍도 설계 → ④ 전원·기동 → ⑤ 성능 확인 탭 순서대로 각 입력값을 확인하고 적합성을 판정합니다.
4
🖨️ 계산서 출력
「🖨️ 계산서 출력」 탭 → A4 미리보기 확인 → [인쇄/PDF 저장] 버튼
인쇄 대화상자에서 「PDF로 저장」 선택 시 PDF 파일로 저장됩니다.
💨 배출량 계산식 (§2.3)
거실 < 400 ㎡ · 벽 구획 (§2.3.1.1)
Q = max(A × 1㎥/min/㎡ × 60, 5,000) [㎥/h]
A: 바닥면적(㎡) | 최소 5,000 ㎥/h
거실 ≥ 400 ㎡, 직경 ≤ 40 m (§2.3.2.1)
Q ≥ 40,000 ㎥/h (벽 구획)
제연경계 시 수직거리별 표 2.3.2.1 적용
거실 ≥ 400 ㎡, 직경 > 40 m (§2.3.2.2)
Q ≥ 45,000 ㎥/h (벽 구획)
제연경계 시 수직거리별 표 2.3.2.2 적용
통로 예상제연구역 (§2.3.3)
Q ≥ 45,000 ㎥/h
제연경계 시 표 2.3.2.2 적용
🌬️ 유입구 · 풍속 · 성능확인
유입구 최소면적 (§2.5.6)
유입구면적(㎠) = 배출량(㎥/min) × 35
풍속 계산
풍속(㎧) = 배출량(㎥/h) ÷ 3,600 ÷ 단면적(㎡)
성능확인 달성률 (§2.10, 신설 2024)
달성률(%) = 측정값 ÷ 설계값 × 100 ≥ 60%
